

# An Analysis of Factors Affecting LLM-based Phishing Detection

This repository contains the code, data processing pipelines, experimental scripts, and analysis used in the paper:

> **An Analysis of Factors Affecting LLM-based Phishing Detection**


## Overview

The repository is organised into five main components:

1. **PreprocessDataObfuscation** – Contains scripts for detecting HTML hidden-text obfuscation in phishing emails.
2. **Parsing** – Contains the parsers that generate the P1 and P2 email representations used in the experiments.
3. **DATA** – Contains a copy of the outputs generated by the parsing pipeline.
4. **LLMClassification** – Contains the scripts for running the LLM phishing detection experiments, including the prompt templates, together with the resulting classification outputs.
5. **ResultsAnalysis** – Contains the statistical analysis scripts and the outptus produced for the results presented in the paper
